# 瓦斯升级与等效战力

升级定义的权威数据源是打包到模拟器中的 `src/star_tarven_simulator/data/upgrades.json`，其来源为仓库根目录 `data/upgrades/upgrades.json`。

## 发现规则

- 玩家花费 2 瓦斯，为一张已进场、升级槽未满的卡牌发现最多 3 个升级。
- 候选池由“公共升级 + 该卡种族专属升级”组成。
- “中立原始升级”只对带有“属于原始虫群”标签的卡牌开放。
- “中立虚影升级”只对带有“具有虚空投影”标签的卡牌开放。
- 普通中立卡不会仅凭 neutral 种族获得上述两个专属池。
- 候选不会包含该卡已经拥有的升级。
- 描述为“不可叠加/无法叠加”的升级不能重复通过其它效果添加；其余升级可重复，仍受默认 5 个升级槽限制。
- 没有候选时不扣瓦斯，也不产生空的强制选择。
- 汉森博士异虫形态继续使用其固定虫族研究池，并返还 1 瓦斯。

## 即时和持续效果

一次性效果直接修改游戏状态，因此其新增单位会自然计入原始战力：

- 修理无人机：增加 `当前酒馆等级 + 3` 个修理无人机。
- 折跃援军：增加 2 高阶圣堂武士和 3 水晶塔；出售时若有合法神族目标，消耗 1 瓦斯，把升级和本卡生物单位复制到随机目标。
- 原始尖塔：增加 2 原始异龙和 4 精华。
- 黄金矿工：保留其回合开始获得矿的事件效果。

战斗类 Buff 不修改单位名称或基础单位价格，而是由等效战力函数解释。

## 等效战力

`Slot.price()` 与 `Tarven.total_power()` 保持原有语义：只统计单位基础价值，保证旧训练目标和 checkpoint 协议不变。

新增：

```python
slot.equivalent_power()
tarven.total_equivalent_power()
```

基本公式：

```text
卡牌等效战力 = 卡牌当前单位基础价值 × Π(每个升级的估值倍率)
```

倍率覆盖以下维度：

- 伤害；
- 攻击速度和时间流逝速度；
- 生命、护盾和减伤；
- 护甲、回复、吸血、免伤与免死；
- 射程、移动、空中化和控制；
- 中毒、反伤、隐身和部署时机；
- 依赖能量强度或场上金色卡数量的动态效果。

这些战斗外推是启发式估值，因为模拟器目前没有敌方阵容、武器类型、实际血量、护盾、战斗时长和伤害日志。具体倍率集中定义在 `star_tarven_simulator/upgrades.py` 的 `POWER_FACTORS`，便于后续用真实战斗数据校准。

一次性增兵不再额外套“增兵倍率”，避免与新增单位的基础价值重复计价。经济效果（例如黄金矿工）也不直接伪装成战斗倍率。
