# 固定英雄系统实施计划

## 目标与约束

- 英雄效果固定写在代码中，不从 `data/heros.json` 加载或解析。
- `build_game(..., heroes=...)` 为玩家分配英雄；未指定为 `default`。
- 每位玩家一个英雄，非 `default` 英雄整局不可重复。
- 使用固定注册表区分可选英雄、变身形态和暂缓英雄。
- 统一使用 `HeroPowerAction`；复杂选择进入 `HeroChoiceAction`。
- `HeroController` 只分发当前英雄的固定主动能力和生命周期钩子，不支持英雄效果组合。
- 凯瑞甘、汉森博士采用固定单向变身；解放者采用固定双模式切换。
- 所有 Python 命令和测试使用 `uv`。

## 暂缓英雄

以下英雄禁止初始选择，后续规则补齐后再实现：

- 泰凯斯
- 界徐盛
- 埃蒙
- 亚顿之矛
- 纳鲁德博士

## Task 1：建立固定英雄注册表和单英雄控制器

- 实现支持、暂缓、变身形态的固定名称集合。
- 给 `Tarven` 添加唯一 `HeroController`。
- 扩展 `build_game()` 的英雄参数和全局唯一校验。
- 测试默认英雄、重复英雄、禁用英雄和形态不可初选。
- Demo：构建多玩家游戏并展示英雄唯一性及禁用英雄错误。

## Task 2：建立统一英雄动作和选择流程

- 新增 `HeroPowerAction`、`HeroChoiceAction`。
- 建立统一的英雄效果分发和卡牌获得/发现辅助接口。
- 为卡池注入可测试 RNG，并正确归还未选择候选。
- 以陆战队员完成首个端到端主动技能。
- Demo：发动技能、支付资源、完成发现并正确处理暂存区溢出。

## Task 3：接入生命周期并实现基础经济英雄

- 接入回合开始/结束、升级、购买、刷新和进场钩子。
- 实现工蜂、副官、矿骡、米拉、德拉肯钻机。
- 测试资源上限、跨回合状态、每级使用次数。
- Demo：连续运行多个回合并观察各英雄资源变化。

## Task 4：实现购买、刷新与锁定英雄

- 实现追猎者、使徒、阿尔达瑞斯、飞蛇。
- 统一统计主动、免费和购买触发刷新。
- 正确处理购买历史、三连折扣和锁定价格。
- Demo：追猎者永久升级，使徒多来源折扣正常叠加。

## Task 5：实现商店模式、放置和开局限制

- 实现收割者、解放者双模式、眼虫。
- 将英雄规则接入放置位置、购买价格、补店和刷新。
- 测试解放者每回合一次模式切换及眼虫前三回合禁购。
- Demo：模式切换立即改变商店行为；眼虫第4回合升至3级。

## Task 6：实现延迟入场和发现型英雄

- 实现航母、诺娃、异龙、响尾蛇、休伯利安点唱机、大力神、飓风。
- 统一候选过滤、卡池消耗、延迟队列和溢出规则。
- 辅助卡集合使用可编辑常量。
- Demo：航母跨回合发现、大力神预选发放、飓风过滤种族。

## Task 7：建立卡牌描述替换、复制和固定变形能力

- 为 `Slot/CardEngine` 添加静态来源、临时描述和派生标记。
- 实现普通卡变金、handler 替换与恢复、初始卡复制、静态定义重载。
- 实现阿巴瑟、雷诺、雷神、机械哨兵、德哈卡、干扰者。
- Demo：雷神描述在三连后恢复，德哈卡转换成原始刺蛇定义。

## Task 8：实现目标卡和单位操作型英雄

- 实现感染虫、SCV、探机、斯旺、蒙斯克、医疗兵、爆虫。
- 扩展虫卵以孵化非英雄机械单位。
- 复用挂件变化、升级和单位增删事件。
- Demo：挂件转换触发快速生产，机械单位转成零件，单位完成均分。

## Task 9：实现融合及专属卡变形

- 实现执政官、阿塔尼斯、母舰核心。
- 支持不可再次融合的动态复合卡。
- 确保融合不触发出售或进场事件。
- Demo：金色异族卡融合、第10张卡合入阿塔尼斯、母舰核心完成变形。

## Task 10：实现虫族孵化、配对、突变和摧毁顺序

- 实现分裂池、混合体、进化腔、扎加拉。
- 保证扎加拉在虫卵孵化前执行。
- 按已确认算法生成突变 A、B 和数量 x。
- Demo：同一回合正确展示摧毁、突变和孵化顺序。

## Task 11：实现星港与凯瑞甘

- 实现星港固定空军模式和随机转换。
- 实现凯瑞甘购买计数、免费刷新和单向异虫变身。
- 变身后永久禁用瓦斯并触发进场升级选择。
- Demo：凯瑞甘购买第 5 张后立即变身并强化场面。

## Task 12：实现汉森博士课题

- 实现五项固定研究课题及 2/4/6 级选择。
- 虫族专属升级使用可编辑常量。
- 新式血清满足条件后清除课题并永久变身。
- Demo：选择课题并通过全虫族场完成异虫形态转换。

## Task 13：实现特殊历史与全场技能

- 实现科学球、火蝠、战列巡航舰。
- 支持观察样本历史累计、连续发现队列和战术跃迁重置。
- Demo：生成累计观察样本、按战力触发多次 5 星发现、酒馆降级后恢复技能。

## Task 14：统一额外相邻关系和战力

- 为坑道虫建立规范化双向额外相邻接口。
- 审计所有直接使用 `left/right` 或槽位差的相邻机制。
- 干扰者英雄将暂存区普通卡静态价值加入 `total_power()`。
- Demo：远端槽位互相供能并触发相邻效果，暂存卡计入战力。

## Task 15：完成全英雄回归与文档

- 为每名支持英雄添加参数化冒烟测试和关键行为断言。
- 验证暂缓英雄不可选择、形态只能通过变身进入。

